# 原始构建输入

`theme.tar.gz` 是本项目适配前收到的 Gloria Universe 极简探针主题包（主题版本 `1.2.0`），用于重复构建 API 适配版。它包含编译后的前端文件，未提供原始 Vue/Vite 工程。

请勿将此文件当作新版安装包。安装适配版请使用仓库根目录的 `theme-api.tar.gz`，或 Releases 中的 `theme.tar.gz`。
